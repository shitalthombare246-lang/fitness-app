# 🏋️ Fitness Tracking Web Application

A Full Stack Java Web Application developed using JSP, Servlets, MySQL, HTML, and CSS.

## 🚀 Features

* User Registration & Login
* Fitness Dashboard
* Calories Tracking
* Activity Simulation
* Result Analysis
* Secure Session Management

## 🛠 Technologies Used

* Java
* JSP & Servlets
* MySQL
* HTML
* CSS
* Apache Tomcat
